ACT I · WHY START SIMPLE?

The easy model is useful. It is not the answer.

At \(x=1.5\,\mathrm{rad}\), replacing \(\sin x\) by \(x\) substantially changes the restoring law and the oscillation period. The approximation is valuable because it gives us a solved starting point — not because it is already accurate.

The starting problem is easy, not accurate. That is exactly why a controlled path to the target is useful.

ACT II · TRANSPORT THE SYSTEM

Move continuously from \(x\) to \(\sin x\).

The embedding coordinate \(q\in[0,1]\) is continuous. The browser will evaluate one GOTHAM deformation while the slider moves; displayed checkpoints are visual samples, not independent optimization runs.

TARGET REACHED

\(q=1\). The system no longer changes.

From this point onward the target is fixed: \(\ddot x+\sin x=0\). The next control, \(M\), changes only the finite-order approximation used to resolve that target.

ACT III · REFINE THE TARGET

Increase \(M\). Do not move \(q\).
