TECHNICAL LAYER

Mathematical formulation

One construction, four depths. Start with the idea; descend only as far as you need.

Level 1What is being constructed?

Start from a solved problem

The nonlinear pendulum is the target:

\[ \ddot x+\sin x=0,\qquad x(0)=A,\quad \dot x(0)=0. \]

The familiar small-angle model provides an analytically solved starting point:

\[ \ddot x_0+x_0=0,\qquad x_0(t)=A\cos t. \]

Build a continuous deformation

Introduce an embedding coordinate \(q\in[0,1]\) and a deformation \(\Phi(t;q)\) satisfying

\[ \Phi(t;0)=x_0(t),\qquad \Phi(t;1)=x(t). \]
qwhere we are along the deformation
Mhow many deformation terms we retain
ħhow finite-order convergence is controlled

Represent the path

\[ \Phi(t;q)=x_0(t)+\sum_{m=1}^{\infty}x_m(t)q^m, \qquad x^{[M]}(t;q)=x_0(t)+\sum_{m=1}^{M}x_m(t)q^m. \]

The web visualizes this same construction from three viewpoints: transport in \(q\), refinement in \(M\), and convergence control through \(\hbar\).

Level 2The operator formulation behind the demo

Operators

Write the target problem as a nonlinear operator equation

\[ \mathcal N[x,\Omega]=0. \]

Choose an auxiliary linear operator \(\mathcal L\) whose inverse problem is simple and compatible with the starting solution \(x_0\).

Zero-order deformation equation

\[ (1-q)\,\mathcal L\!\left[\Phi-x_0\right] = q\,\hbar\,\mathcal N[\Phi,\Omega]. \]

This is the central mathematical bridge. At the two endpoints:

\(q=0\)\[\mathcal L[\Phi-x_0]=0\Rightarrow\Phi=x_0\]
\(q=1\)\[\hbar\,\mathcal N[\Phi,\Omega]=0\Rightarrow\mathcal N[\Phi,\Omega]=0\]

Series and transported time scale

\[ \Phi(\tau;q)=\sum_{m=0}^{\infty}x_m(\tau)q^m, \qquad \Omega^2(q)=\sum_{m=0}^{\infty}\omega_m q^m, \qquad \tau=\Omega(q)t. \]

Transporting the frequency together with the waveform is essential for a periodic problem: otherwise a small frequency error becomes a growing phase error in physical time.

The pendulum used here

In normalized time, the target residual has the structure

\[ \mathcal N[\Phi,\Omega] = \Omega^2\,\partial_{\tau\tau}\Phi+\sin\Phi. \]

The auxiliary problem is anchored to the harmonic oscillator. The browser implementation uses a frequency-corrected \(q\)-series so that each finite order carries both waveform and period information.

Level 3How the deformation generates the hierarchy

Differentiate with respect to q

Apply the \(m\)-th homotopy derivative to the zero-order deformation equation and evaluate at \(q=0\). With

\[ x_m= \left. \frac{1}{m!}\frac{\partial^m\Phi}{\partial q^m} \right|_{q=0}, \]

the nonlinear problem is converted into a sequence of linear deformation problems.

m-th order deformation equation

\[ \mathcal L\!\left[x_m-\chi_m x_{m-1}\right] = \hbar\,R_m, \qquad \chi_m= \begin{cases} 0,&m=1,\\ 1,&m>1. \end{cases} \] \[ R_m= \left. \frac{1}{(m-1)!} \frac{\partial^{m-1}}{\partial q^{m-1}} \mathcal N[\Phi(q),\Omega(q)] \right|_{q=0}. \]

Recursive structure

\(x_0,\Omega_0\)→ build\(R_1\)→ solve\(x_1,\omega_1\)→\(R_2\)→ solve\(x_2,\omega_2\)→ ···

At each order, previously computed terms determine the forcing \(R_m\). The auxiliary operator is solved again; the original nonlinear problem is not restarted from scratch.

Periodic solvability and frequency correction

For the pendulum, resonant forcing would generate secular terms. The frequency coefficients \(\omega_m\) are therefore chosen order by order so that the resonant component is removed. This is what lets the approximation remain periodic while its physical period deforms.

Finite order and convergence control

Stopping the hierarchy at \(M\) gives a computable approximation. In the generalized finite-order construction used by the demo, \(\hbar\) changes the effective weighting of retained deformation terms:

\[ x_{\hbar}^{[M]} = \sum_{n=0}^{M}\mu_{M,n}(\hbar)\,x_n. \]

Hence \(M\) and \(\hbar\) have fundamentally different roles: one sets the available order; the other reshapes how that finite information converges.

From computation to the q–M frontier

For a tolerance \(\varepsilon\), the browser checks these diagnostics over the sampled \(q\)-grid and reports

\[ q_{\max}(M;\varepsilon), \qquad M_{\min}(q;\varepsilon). \]

This is the computational meaning of “Go Farther”: increasing the available order can extend the portion of the homotopy path that is resolved reliably.
